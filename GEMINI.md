# Racing Life 3D

- src/main.js is the active application entry.
- Do not modify unrelated files.
- Preserve existing folder structure.
- Vehicle classes extend THREE.Group.
- Vehicle constructors must not return a nested group.
- A/Left = -1 and D/Right = +1.
- Keep steering and wheel-roll pivots separate.
- Do not use geometry.scale.set(); use mesh.scale.set().
- Test vehicle changes through the dedicated test HTML first.
- Never replace a whole working system unless explicitly requested.
